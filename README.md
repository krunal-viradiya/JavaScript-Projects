## 🌟 Featured Project: Weather App (`weatherProject`)

A clean, responsive weather forecast application that pulls real-time weather data from an external API and provides instant weather conditions for any searched city.

### ✨ Key Features
- **Real-Time Data:** Live metrics including current temperature, weather conditions, and humidity.
- **City Search:** Search functionality allowing users to look up weather reports worldwide.
- **Dynamic DOM Rendering:** Seamlessly updates the UI and weather icons according to API response data.
- **Graceful Error Handling:** Provides user-friendly alerts when an invalid location is entered or network errors occur.

### 🛠️ Built With
- **HTML5:** Semantic structure and layout.
- **CSS3:** Modern styling, flexbox/grid layout, and responsive design.
- **JavaScript (ES6+):** Fetch API, Async/Await functions, and Event Listeners.

## ⚙️ How to Run Locally

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/krunal-viradiya/JavaScript-Projects.git
   ```

2. Navigate into the repository directory:
   ```bash
   cd JavaScript-Projects
   ```

3. Change directory to the Weather Project:
   ```bash
   cd weatherProject
   ```

4. Launch `index.html` in your favorite web browser or start a local server using VS Code's Live Server extension.
